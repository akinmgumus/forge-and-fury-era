GEMINI PROMPT - HEROES III ARTIFACT ICON
========================================

How to use:
1. Attach "_style reference sheet.png" (and, for a combination artifact, the icons of its parts).
2. Copy the TEMPLATE below and replace the [...] parts.
3. Generate a few versions, pick the one that is easiest to read when you shrink it very small.
4. Give the big image to Claude: it is cropped, the background is removed and it is scaled to 44x44.


TEMPLATE
--------
Create a single fantasy item icon in the exact style of Heroes of Might and Magic III (1999)
artifact icons, like the attached reference sheet: hand-painted / pre-rendered look, bold
silhouette, rich saturated colors, strong highlights, a thin dark outline, lit from the upper left.

Item: [ITEM NAME], a [ITEM TYPE: necklace / ring / cloak / helmet / sword / shield / boots ...].
Description: [WHAT IT LOOKS LIKE: materials, colors, gems, symbols].
[FOR COMBINATION ARTIFACTS: It is forged from [PART 1], [PART 2] and [PART 3] (attached), so it
should clearly combine their shapes and colors into one new item.]

Composition: one item only, centered, filling about 85% of a square canvas, seen from the front
or at a slight angle, no hands, no character, no scenery.
Background: a completely flat, solid pure magenta (#FF00FF) background with no gradient, no
shadow and no glow on the background.
No text, no frame, no border, no watermark.

Square image, high resolution (1024x1024). The item must stay clearly recognizable when
downscaled to 44x44 pixels: simple strong shapes, high contrast, no tiny details.

TIPS
----
- If the result looks too modern / too detailed, add:
  "make it look like a 1999 pre-rendered game icon, fewer details, chunkier shapes".
- If Gemini adds a shadow or a colored glow on the background, ask again:
  "the background must be one flat magenta color only".
- Magenta is used because it never appears in the icon itself, so it can be removed cleanly.
